# 翻訳

ヘッダーの「翻訳」からブラウザー内蔵AIで文章を翻訳する。
デスクトップ版Chromeと、対応する内蔵モデルを使う。
対応していない環境では画面の案内を確認し、対応するブラウザーで開く。

## 言語とエンジン

「入力側の言語（母語）」と「母語のときの翻訳先」を選ぶ。
原文が母語なら指定した翻訳先へ、それ以外なら母語へ翻訳する。
使用可能なエンジンがある場合は、Translator APIまたはPrompt APIを選べる。
選択したエンジンの準備状況を画面下部で確認する。
モデルの準備が必要な場合は、翻訳方向を選び、準備ボタンを押す。
ダウンロード中は進捗を表示する。

## 入力とコピー

「原文」へ文章を入力すると、入力停止後に自動翻訳して「訳文」へ表示する。
入力や言語設定を変えると、その内容で翻訳をやり直す。
訳文の「コピー」を押すとクリップボードへコピーする。
言語とエンジンの選択は保存され、次に開いたときも使われる。

モデルのダウンロードにはネットワーク接続が必要で、準備後の翻訳はブラウザー内で処理する。

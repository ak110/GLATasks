# タスクとリスト

リストを選び、追加欄からタスクを登録する。
変更は他の端末やタブへも反映される。

## リストの管理

「新しいリスト」へ名前を入力して追加する。
リスト名を押すと、そのリストのタスクを表示する。
リストのメニューから名前変更、アーカイブ、「他のリストに統合」、削除、定期TODOの管理を選べる。
「他のリストに統合」は移動先のリストを選んで確定する。
タスクと定期TODOを移動先へまとめ、移動元のリストを削除する。
リストを削除すると、そのリストのタスク、添付ファイル、定期TODOも削除する。
タスクリストの「完了済みを非表示」ボタンで、完了したタスクを非表示にする。

## タスクの追加と編集

タスクの追加欄へ本文を入力し、追加ボタンを押す。
タイトルとメモを分けて保存し、編集ボタンから本文、タグ、TODO区分などを変更できる。
TODO区分の未完了タスクはリストの通知バッジへ数える。
チェック欄を押すと未着手、実行中、完了の順に切り替わる。
実行中のタスクは完了済みタスクの非表示の対象に含まれない。
コピーのメニューから本文全体、タイトルのみ、メモのみを選べる。

ドラッグハンドルでタスクを並べ替える。
リスト一覧とタスクを横に表示できる広い画面では、別リストへドラッグして移動できる。
検索欄からタスクを検索し、表示種別でアクティブ、アーカイブ、すべてを切り替える。
アーカイブ表示でもリスト一覧はすべてのリストを表示する。

## ファイルの添付

編集画面でファイルを選ぶか、ファイルをドロップして添付する。
クリップボードの画像も貼り付けられる。
画像はサムネイルを押すと拡大表示し、画像以外は添付アイコンを押すとダウンロードする。
不要な添付は編集画面で削除する。

Webページからの登録は[Chrome拡張機能](./chrome-extension.md)、Androidからの登録は[Android共有](./android-share.md)を参照。

# Chrome 拡張機能

現在のページのタイトルとURLを簡単にGLATasksに保存するためのChrome拡張機能。

## 機能

- 右クリックメニュー: ページ上で右クリックして「GLATasksに保存する」を選択
- 拡張機能アイコン: ツールバーの拡張機能アイコンをクリック

どちらの方法でも、現在のページのタイトルとURLを使ってタスクの取り込みページを新しいタブで開く。

## インストール手順

1. Chrome拡張機能の管理ページを開く
   - Chromeのアドレスバーに`chrome://extensions/`と入力
   - またはChromeメニューから「その他のツール」「拡張機能」の順に選択
2. 「デベロッパーモード」を有効にする（右上のトグルスイッチ）
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`chrome_extension/`を選択する
4. 拡張機能がインストールされ、ツールバーにアイコンが表示される

## 使用方法

右クリックメニューからは、ページ上で右クリックして「GLATasksに保存する」を選択する。
拡張機能アイコンからは、ツールバーのアイコンをクリックしてポップアップのボタンを押す。
どちらの方法でも新しいタブでGLATasksの取り込みページが開く。

# Chrome拡張機能

現在のページのタイトルとURLをGLATasksに保存するChrome拡張機能。

## 機能

- 右クリックメニュー: ページ上で右クリックして「GLATasksに保存する」を選択
- 拡張機能アイコン: ツールバーの拡張機能アイコンをクリック

右クリックメニューは取り込みページを新しいタブで開く。
アイコンはポップアップ内に取り込みページを読み込む。
どちらも現在のページのタイトルとURLを取り込む。

## インストール手順

拡張機能を使うPCへ[GLATasksのリポジトリ](https://github.com/ak110/GLATasks)を取得する。
Gitを使う場合は`git clone`で複製し、使わない場合はリポジトリのページの「Code」から「Download ZIP」でZIPファイルを保存して展開する。
以下の手順では、取得したリポジトリ内の`chrome_extension/`ディレクトリーを選ぶ。

1. Chrome拡張機能の管理ページを開く
   - Chromeのアドレスバーに`chrome://extensions/`と入力
   - またはChromeメニューから「その他のツール」→「拡張機能」の順に選択
2. 「デベロッパーモード」を有効化（右上のトグルスイッチ）
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`chrome_extension/`を選択
4. 拡張機能がインストールされ、ツールバーにアイコンが表示される

接続先は`https://glatasks.tqzh.tk`に設定されている。
自分のサーバーで使う場合は、読み込む前に`chrome_extension/background.js`と`chrome_extension/popup.js`の接続先URLを自分のサーバーのURLへ書き換える。
変更後は拡張機能の管理ページで再読み込みする。

## 使用方法

右クリックメニューからはページ上で右クリックして「GLATasksに保存する」を選択。
拡張機能アイコンからはツールバーのアイコンをクリックし、ポップアップ内の取り込み画面を操作する。
表示された内容を確認して保存先のリストを選び、タスクを登録する。

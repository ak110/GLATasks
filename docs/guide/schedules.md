# 定期TODO

リストの「⋯」メニューから定期TODOを開く。
指定した繰り返しルールで、そのリストへTODOタスクを自動追加する。

## 設定

追加画面へタイトルとタグを入力する。
頻度、間隔、曜日や日付、時刻、終了条件を指定して追加する。
時刻は端末のタイムゾーンによらず日本時間（`Asia/Tokyo`）として扱う。
一覧のON/OFFで自動追加を切り替え、編集ボタンでルールを変更する。
削除すると設定を取り除き、すでに生成されたTODOは残る。

サーバーは起動時と定期処理で、過ぎた予定をさかのぼって生成する。
1回の処理で生成するのは各設定について30件までで、上限を超えた予定はスキップする。
長く停止していたサーバーを再起動する場合は、必要なTODOが生成されたかリストを確認する。

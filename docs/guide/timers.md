# タイマーとアラーム

ヘッダーの「タイマー」を開き、タイマーを追加・操作する。
タイマーはカウントダウンとアラームの2モードを持つ。

## 追加

「追加」を押し、名前とモードを指定する。
カウントダウンでは「ベース時間」に`HH:MM:SS`形式で時間を入力する。
アラームでは「目標時刻」に端末の現地時刻を指定する。
「延長/削減の単位（分）」と「鳴らす時間（秒）」も指定して保存する。
現在のフォーム値は初期値として保存できる。

「一時タイマー」は一度使って削除するタイマーで、作成直後に開始する。
満了後は削除ボタンが強調され、確認なしで削除できる。

## 操作

各タイマーの開始、一時停止、リセット、延長、削減の操作を使う。
残り時間の変更と名前・設定の編集も行える。
ドラッグハンドルで表示順を変えられる。
満了すると指定した時間だけ音を鳴らし、停止操作で止められる。
ブラウザーで音声再生が許可されていることを確認する。

残り時間はサーバーとの時刻差を補正して表示する。
別のタブや端末で開始・停止した場合も表示へ反映される。
